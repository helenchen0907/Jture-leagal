Privacy Policy

1. Data Processing Principles

Jture is designed with a privacy-first architecture. User resume data and job application information are stored locally on the user's device and, if enabled by the user, synchronized via iCloud. We do not persistently store personal data on our own servers.

2. AI Services and User Consent

Certain features in Jture are powered by DeepSeek AI.

AI processing occurs only when the user explicitly initiates an AI feature (such as job description analysis or form assistance). Before the first AI request, users are clearly informed about:

  • What data is sent
  • The AI provider involved (DeepSeek)
  • The purpose of processing

Users must explicitly consent before any data is transmitted. Users may decline AI usage and continue using non-AI features of the app.

AI-generated content is provided for assistance only. Users are responsible for reviewing and verifying all AI-generated outputs before submission.

3. In-App Browser and Form Assistance

Jture includes an in-app browser to help users manage job applications.

Form assistance operates only on user-provided resume data and does not access login credentials, passwords, or authentication fields. Jture does not collect or store credentials for third-party websites.

4. Data Scope

Depending on user actions, Jture may process:

  • Resume content provided by the user
  • Job description text
  • Application tracking metadata
  • App usage data required for functionality

5. User Control

Users may:

  • Delete local data at any time
  • Disable AI features
  • Revoke AI usage authorization at any time in App settings
  • Control iCloud synchronization through system settings

1. 데이터 처리 원칙

Jture는 개인정보 보호를 최우선으로 하는 아키텍처로 설계되었습니다. 사용자의 이력서 데이터와 구직 지원 정보는 사용자의 기기에 로컬로 저장되며, 사용자가 활성화한 경우 iCloud를 통해 동기화됩니다. 당사는 자체 서버에 개인 데이터를 영구적으로 저장하지 않습니다.

2. AI 서비스 및 사용자 동의

Jture의 일부 기능은 DeepSeek AI로 구동됩니다.

AI 처리는 사용자가 명시적으로 AI 기능(채용공고 분석 또는 양식 지원 등)을 시작할 때만 수행됩니다. 첫 번째 AI 요청 전에 사용자에게 다음 사항이 명확히 안내됩니다:

  • 전송되는 데이터 내용
  • 관련 AI 제공업체(DeepSeek)
  • 처리 목적

데이터가 전송되기 전에 사용자는 명시적으로 동의해야 합니다. 사용자는 AI 사용을 거부하고 앱의 비 AI 기능을 계속 사용할 수 있습니다.

AI가 생성한 콘텐츠는 지원 목적으로만 제공됩니다. 사용자는 제출 전에 모든 AI 생성 결과물을 검토하고 확인할 책임이 있습니다.

3. 앱 내 브라우저 및 양식 지원

Jture에는 사용자가 구직 지원을 관리할 수 있도록 앱 내 브라우저가 포함되어 있습니다.

4. 데이터 범위

사용자 작업에 따라 Jture는 다음을 처리할 수 있습니다:

  • 사용자가 제공한 이력서 내용
